# Домашняя библиотека (Home Library Catalog)

## Описание модели

Система представляет собой каталог домашней библиотеки, позволяющий управлять коллекцией книг, отслеживать их местоположение, выдачу и возврат.

### Основные сущности

- **Книга (Book)** — неизменяемая сущность (`record`), описывающая произведение. Равенство определяется по ISBN. Содержит название, автора и жанр.
- **Автор (Author)** — неизменяемая сущность (`record`), хранит имя и фамилию автора.
- **Экземпляр книги (BookCopy)** — физический объект книги в библиотеке. Содержит изменяемое состояние: условие хранения, местоположение, текущую выдачу и историю выдач.
- **Местоположение (Location)** — неизменяемая сущность (`record`), описывающая адрес экземпляра по схеме «Комната → Шкаф → Полка».
- **Выдача (Loan)** — неизменяемая сущность (`record`), фиксирует факт выдачи книги читателю с датой выдачи и сроком возврата.

### Перечисления

- **Genre** — жанр книги (с полями и описанием): Художественная проза, Научная литература, Фэнтези, Детектив.
- **Condition** — состояние экземпляра: NEW, GOOD, WORN, DAMAGED.

### Полиморфный поиск

Реализован через `sealed interface SearchCriteria` с тремя вариантами критериев:
- `ByAuthor` — поиск по автору
- `ByTitle` — поиск по названию
- `ByGenre` — поиск по жанру

Обработка критериев осуществляется через `switch` с сопоставлением с образцом (pattern matching).

## Реализованные возможности

### Базовый уровень

- ✅ Добавление экземпляров в библиотеку
- ✅ Поиск по автору, названию и жанру
- ✅ Получение полного адреса местоположения экземпляра
- ✅ Выдача экземпляра читателю с указанием срока возврата
- ✅ Возврат экземпляра в библиотеку
- ✅ Получение списка всех выданных экземпляров
- ✅ Получение списка просроченных экземпляров на заданную дату
- ✅ Обработка попытки выдачи уже выданного экземпляра (исключение `BookAlreadyIssuedException`)
- ✅ Обработка попытки возврата невыданного экземпляра (исключение `BookNotIssuedException`)

### Повышенный уровень

- ✅ Перестановка: перенос полки с автоматическим обновлением адресов всех экземпляров на ней
- ✅ История выдач по экземпляру книги
- ✅ Отчёт о занятости полок (количество экземпляров на каждой полке)
- ✅ Отчёт о распределении фонда по жанрам

## Ключевые особенности реализации

- **Java 21**: активное использование современных возможностей языка
    - `record` для неизменяемых значений (Book, Author, Location, Loan)
    - `sealed interface` для закрытой иерархии критериев поиска
    - `switch` как выражение с сопоставлением с образцом (pattern matching)
    - `var` для локальных переменных
- **Инкапсуляция**: все поля закрыты, изменяемое состояние не утекает наружу (возвращаются неизменяемые копии коллекций через `List.copyOf()` и `Collections.unmodifiableList()`)
- **Тестирование**: 12 сценариев на JUnit 5, покрывающих граничные случаи, проверку исключений (`assertThrows`), контракт `equals/hashCode` и инкапсуляцию
- **Документация**: Javadoc на все публичные методы модели
